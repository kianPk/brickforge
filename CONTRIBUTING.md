# Contributing

Thanks for improving Brickforge.

## Playable file

Edit `PLAY.html`, then copy it to `docs/index.html` (GitHub Pages source) so the live demo stays in sync:

```bash
cp PLAY.html docs/index.html
```

## Guidelines

- Keep the game self-contained (no build step)
- Prefer small, testable gameplay changes
- Update `CHANGELOG.md` for user-visible changes

## Local check

Open `PLAY.html` in a browser, or serve the repo root / `docs/` with any static server.
