# Brickforge

Brick-breaker with multi-ball, wide paddle, slow-mo power-ups, particle bursts, and stage clear.

[![Demo](https://img.shields.io/badge/demo-live-0f1a22?style=for-the-badge)](https://kianpk.github.io/brickforge/)
[![License: MIT](https://img.shields.io/badge/license-MIT-green?style=flat-square)](./LICENSE)

## Play

**https://kianpk.github.io/brickforge/**

## Controls

- Mouse / touch to move paddle
- ← → keys also work

## Stack

Vanilla JS · HTML5 Canvas/SVG · CSS · GitHub Pages

No frameworks. Runs offline once loaded.

## Local

```bash
python3 -m http.server 8080 --directory docs
# open http://localhost:8080
```
